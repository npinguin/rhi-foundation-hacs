# RHI Foundation

Foundation provides discovery, device identity and configuration support for RHI integrations.

## Installation

Add `https://github.com/npinguin/rhi-foundation-hacs` as a custom Integration repository in HACS. Choose the appropriate published version, back up Home Assistant and restart after installation. Test versions are not production-approved.
